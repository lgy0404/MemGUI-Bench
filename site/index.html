Overview

MemGUI-Bench evaluates memory capabilities that are central to mobile GUI agents: retaining information from earlier UI states, carrying facts across applications, and avoiding memory hallucination during long trajectories.

The benchmark includes 128 tasks over 26 apps. Tasks average 36.2 golden steps, 78.1% involve multiple apps, and 89.8% require UI memory.

Benchmark Comparison

MemGUI-Bench focuses on memory-intensive mobile use. Compared with general mobile-agent benchmarks, it stresses long-horizon execution, cross-app information transfer, and dedicated memory metrics.

MobileWorld Runtime

The open-source MemGUI-Bench runner now follows the MobileWorld-androidworld architecture: Docker-managed Android environments, one container per parallel emulator, MobileWorld action parsing and actuation, local traj_logs/, and the shared trajectory viewer. 

uv run mg env init
sudo uv run mg env check
sudo uv run mg env run --count 4 --launch-interval 20
sudo uv run mg eval \
  --agent-type qwen3vl \
  --model-name qwen3-vl-8b \
  --task ALL \
  --log-file-root traj_logs/memgui-qwen3vl \
  --max-concurrency 4
uv run mg logs view --log-dir traj_logs/memgui-qwen3vl
  1. Pull and launch the pre-configured MemGUI Docker image.
  2. Run agents through the MobileWorld environment queue.
  3. Store trajectories on the host in MobileWorld format.
  4. Score each trajectory with MemGUI-Eval.

Evaluation Pipeline

Execution and logging use MobileWorld. Scoring remains MemGUI-specific: the evaluator generates step descriptions, makes a final decision, computes information retention, and classifies bad cases. A compatibility workspace is generated under _memgui_eval/ while the public trajectory remains traj.json, screenshots, marked screenshots, and result.txt.

System Architecture

MemGUI-Bench reuses MobileWorld's container orchestration, backend API, environment queue, controller, action execution, and log viewer. The benchmark-specific pieces are the MemGUI task registry, MemGUI-Eval scoring bridge, and the configured MemGUI Docker image.
